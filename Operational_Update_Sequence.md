# Operational Update Sequence

**Protocol for code, model, and parameter handling**

**Use quick fix → UPDATE ALL → undo → Timestamp → do it again → use “syntax” to “autocorrect”.**

When applying updates or corrections:
- Quick fix: stage on a copy.
- UPDATE ALL: push to dependents.
- Undo: roll back and verify original.
- Timestamp: log with time.
- Do it again: reapply and confirm match.
- “Syntax” to “autocorrect”: validate and fix only clear formatting issues.

Active in the current metastasis simulation runs. Speculative modeling only.
